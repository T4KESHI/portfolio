AR床置きテスト一式

内容
- index.html : AR表示ページ
- models/test-object.glb : 高さ約1.12mの簡易テストモデル

使い方
1. このフォルダの中身をHTTPS対応のWebサーバー（例: GitHub Pages）にアップロードします。
2. 公開された index.html をスマートフォンで開きます。
3. 3D表示を確認し、「部屋に置いてみる」を押します。

注意
- file:// で直接開くのではなく、HTTPSで公開してください。
- iPhoneはSafariで確認してください。
- AndroidはARCore対応端末・対応ブラウザが必要です。
- model-viewer 4.4.0をGoogle Hosted Librariesから読み込みます。
- テストモデルは実際のドレスデータではありません。高さ約1.12mの簡易オブジェクトです。
